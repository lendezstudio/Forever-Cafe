# Forever Cafe & Lounge

Static website for Forever Cafe and Lounge, Ormoc City. Designed by Lendez Studio.

## Upload to GitHub
1. Create a repository named Forever-Cafe.
2. Upload the contents of this folder at the repository root: index.html, style.css, app.js, assets, and .nojekyll.
3. Commit to main.
4. To host it: Settings > Pages > Deploy from a branch > main > /(root) > Save.

No installation or build command is required. All paths support GitHub Pages project hosting.

## Preview locally
Run `python -m http.server 8000` from this folder, then open http://localhost:8000.

## Editing
- index.html: page copy and navigation
- style.css: branding and responsive layout
- app.js: menu items, filters, photo mapping, slideshow
- assets/: website photos and logo

## Images
Includes stock images, product images from the cafe's delivery listing, and generated representative drink images. These are not all photographs of the cafe's actual served products. Replace with approved client photos when available. Prices currently reflect the delivery listing.

The original Sites website is independent of this GitHub copy. Future edits must be synchronized manually.
